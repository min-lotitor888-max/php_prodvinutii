## Задание 2. Создание классов

Созданы три класса. В каждом есть свойства, обычные методы и простые статические элементы (дополнительное задание).

| Класс | Свойства | Методы |
|---|---|---|
| `Student` | `name`, `age`, `course` | `introduce()`, `study()`, `getMinAge()` (статический) |
| `Car` | `brand`, `color`, `speed` | `start()`, `stop()`, `getWheels()` (статический) |
| `Television` | `brand`, `channel`, `isOn` | `turnOn()`, `changeChannel()`, `getMaxChannel()` (статический) |

Статические элементы самые простые:

- минимальный возраст студента — 16 лет;
- количество колёс у машины — 4;
- максимальный номер канала — 99.

Свойства задаются в конструкторе. Методы меняют состояние объекта и возвращают текст для вывода.

## Задание 3. Автозагрузчик и работа с классами

Классы из задания 2 разложены по папкам, у каждого появилось пространство имён:

| Класс | Пространство имён | Файл |
|---|---|---|
| `Student` | `Homework\Object\Human` | `src/Object/Human/Student.php` |
| `Car` | `Homework\Object\Technics\Transport` | `src/Object/Technics/Transport/Car.php` |
| `Television` | `Homework\Object\Technics\Household` | `src/Object/Technics/Household/Television.php` |

Автозагрузчик находится в `task-03/autoload.php`:

```php
<?php

spl_autoload_register(function ($class) {
    $prefix = 'Homework\\';
    $baseDir = __DIR__ . '/src/';

    if (strpos($class, $prefix) !== 0) {
        return;
    }

    $path = substr($class, strlen($prefix));
    $file = $baseDir . str_replace('\\', '/', $path) . '.php';

    if (file_exists($file)) {
        require $file;
    }
});
```

Он заменяет `\` на `/` и подключает нужный файл. Например, класс `Homework\Object\Human\Student` загружается из `src/Object/Human/Student.php`.

В `demo.php` созданы объекты всех трёх классов, свойства заполнены через конструктор, вызваны обычные и статические методы.

### Запуск

```bash
php task-03/demo.php
```
